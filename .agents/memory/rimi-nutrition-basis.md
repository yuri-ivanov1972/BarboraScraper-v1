USDA-enriched nutrition values stored in the Rimi database are per 100 g of edible food.

**Why:** The user explicitly confirmed this basis on October 11, 2026, after metadata and available code could not establish the external importer's convention.

**How to apply:** Use these stored values without retail-pack scaling when importing approved Rimi references. This confirmation does not cover other nutrition origins or establish the correctness of individual USDA matches.
